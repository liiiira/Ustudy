# 02 — Database Design

## Initial Schema

For the first version of UStudy, I designed a relational database using **PostgreSQL**.

The initial schema focuses on the core entities of the application and the relationships between them. I used primary keys and foreign keys to represent these relationships and enforce basic data integrity at the database level.

![Initial Database Schema](./images/initial-database-schema.png)

> **Figure 1 — Initial UStudy database schema**

The schema is designed to evolve as new features are introduced. To manage this evolution, I use **database migrations** with a forward-only strategy.

## Database Migrations

Instead of modifying the database schema manually, each change is represented by a new migration that moves the database from its current state to the next one.

```text
Migration 001
add users
      ↓
Migration 002
Add communities
      ↓
Migration 003
Add posts
      ↓
Migration 004
Add comments
