# 04 — User CRUD

The backend currently provides the babut isic CRUD operations for users.

Authentication and authorization are not implemented yet, so these endpoints are currently accessible without requiring a logged-in user.

## Create User

POST /api/v1/users

Creates a new user.

### Body

{
"username": "kira",
"email": "[kira@gmail.com](mailto:kira@gmail.com)",
"password": "12345678"
}

The password is hashed before being stored in the database.

---

## Get All Users

GET /api/v1/users

Returns all users.

### Parameters

No path parameters or request body are required.

---

## Get User

GET /api/v1/users/

Returns a specific user by their ID.

### Path Parameters

id — UUID of the user

### Body

No request body is required.

---

## Update User

PATCH /api/v1/users/

Updates one or more fields of an existing user.

### Path Parameters

id — UUID of the user

### Body

The fields are optional, allowing partial updates.

{
"username": "new_username",
"email": "[new@email.com](mailto:new@email.com)",
"password": "new_password"
}

Only the fields provided in the request are updated.

---

## Delete User

DELETE /api/v1/users/

Deletes a user by their ID.

### Path Parameters

id — UUID of the user

### Body

No request body is required.

The endpoint returns the ID of the deleted user along with a success message.

---

## Summary

| Method | Endpoint       | Purpose       |
| ------ | -------------- | ------------- |
| POST   | /users/        | Create a user |
| GET    | /users/        | Get all users |
| GET    | /users/:id/    | Get one user  |
| PATCH  | /users/:id/    | Update a user |
| DELETE | /users/:id/    | Delete a user |

Authentication and authorization will be added in a later stage. For now, the CRUD endpoints do not restrict access based on the user's identity or permissions.
